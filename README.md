# برنامج الغياب اليومي - مدرسة جوفاء للبنين

## 📚 نبذة عن البرنامج

برنامج احترافي لإدارة الغياب اليومي في مدرسة جوفاء للتعليم الأساسي (5-12)

### ✨ المميزات:
- ✅ تسجيل الحضور حسب الصف والحصة
- 📊 إحصائيات عامة للمدرسة
- 📱 تطبيق محمول سهل الاستخدام
- 🖨️ طباعة التقارير
- 💾 تخزين البيانات محليًا
- 🔄 عمل بدون اتصال بالإنترنت (PWA)

## 🎯 كيفية الاستخدام:

### على الويب:
1. اختر الصف من القائمة المنسدلة
2. اختر الحصة والتاريخ
3. اضغط على حالة كل طالب (حاضر/غائب/متأخر)
4. احفظ البيانات

### على الهاتف:
1. افتح التطبيق على هاتفك الذكي
2. اختر الصف
3. اختر الحصة والتاريخ
4. سجل الحضور بسهولة
5. احفظ البيانات

## 👨‍💼 معلومات المدرسة:

- **اسم المدرسة:** مدرسة جوفاء للتعليم الأساسي (5-12) بنين
- **مدير المدرسة:** ناصر العمري
- **التصميم:** أ/ وليد علي صبره
- **عدد الحصص:** 8 حصص يومية

## 💡 ملاحظات مهمة:

- يعمل البرنامج بدون اتصال إنترنت
